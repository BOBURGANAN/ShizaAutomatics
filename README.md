# ShizaAutomatics 1.01

Надстройка для **AutoCAD 2025 под Windows x64**. Добавляет вкладку ShizaAutomatics, библиотеку блоков и переключатель масштаба оформления в нижней строке состояния.

## Установка

Скачайте архив из [раздела релизов](https://github.com/BOBURGANAN/ShizaAutomatics/releases) и распакуйте его. Выберите один из способов установки.

### Автоматическая загрузка при запуске

1. Закройте AutoCAD.
2. Скопируйте папку `ShizaAutomatics.bundle` целиком в `%APPDATA%\Autodesk\ApplicationPlugins`. Если папки `ApplicationPlugins` нет, создайте её. Файл `PackageContents.xml` должен лежать непосредственно в `ShizaAutomatics.bundle`.
3. Запустите AutoCAD 2025 и откройте чертёж. AutoCAD сам загрузит надстройку из `ApplicationPlugins`. [Установка пакетов AutoCAD](https://help.autodesk.com/cloudhelp/2025/ENU/AutoCAD-Customization/files/GUID-5E50A846-C80B-4FFD-8DD3-C20B22098008.htm)

### Ручная загрузка из выбранной папки

1. Сохраните папку `ShizaAutomatics.bundle` целиком там, где она будет храниться постоянно, например `D:\CAD\ShizaAutomatics.bundle`. Команда «Сохранить блок» требует доступа на запись в подпапку `Contents\Library`.
2. В открытом чертеже введите `_NETLOAD` и выберите `Contents\ShizaAutomatics.dll`. Повторяйте этот шаг после каждого запуска AutoCAD. [NETLOAD](https://help.autodesk.com/cloudhelp/2025/ENG/AutoCAD-Core/files/GUID-D954BCC1-C4F0-488B-8F60-1D02D68940E0.htm)
3. При первой установке введите `_CUILOAD`, нажмите «Обзор» и загрузите `Contents\ShizaAutomatics.cuix` из той же папки. AutoCAD запомнит расположение файла ленты в текущем профиле. [Загрузка файла CUIx](https://help.autodesk.com/cloudhelp/2022/ENU/AutoCAD-Customization/files/GUID-55B0E62E-9F40-4A95-BCE6-180EB47C9DDD.htm)

После загрузки появятся вкладка **ShizaAutomatics** на ленте и кнопка **Оформление 1:100** в строке состояния. Если лента скрыта, введите `_RIBBON`.

Сборка без цифровой подписи. Если AutoCAD попросит разрешение, сверьте путь к `ShizaAutomatics.dll` с папкой установленной надстройки и подтвердите загрузку. Если политика вашей организации запрещает загрузку, обратитесь к CAD-администратору.

## Возможности

| Раздел | Команда | Что делает |
| --- | --- | --- |
| Исходники | `B0` | Переносит содержимое выбранных блоков на слой 0. Общие определения меняются для всех их вставок. |
| Исходники | `COPYKEEP` | Создаёт копии выбранных объектов на слое 0. |
| Исходники | `PDFROW` | Импортирует страницы PDF и размещает их в ряд. |
| Объекты из базы | `SHIZALIBRARY` | Открывает каталог DWG с категориями, поиском и миниатюрами. |
| Объекты из базы | `SHIZASAVEBLOCK` | Сохраняет выбранный блок из чертежа в библиотеку. |
| Оформление | `SHIZALEVELS` | Пересчитывает высотные отметки по опорному значению и разнице координат Y. |
| Оформление | `SHIZAALIGNLEVELS` | Выравнивает высотные отметки по опорной с сохранением высоты и числового значения каждой метки. |

Блоки категории **Оформление** вставляются в текущем масштабе. После вставки масштаб хранится у каждого экземпляра. При выделении блока оформления нижняя кнопка показывает его масштаб и меняет его по выбору. Блоки остальных категорий вставляются **1:1**.

С версии **1.01** выбор масштаба также применяется к штатным размерам, мультивыноскам, выноскам и тексту AutoCAD. С пустым выделением он задаёт масштаб для новых объектов. С выделением меняет оформление выбранных объектов. Измеряемые значения размеров сохраняются.

Элементы библиотеки находятся в `ShizaAutomatics.bundle\Contents\Library`. Подпапки задают категории. Новый DWG появится в каталоге при следующем открытии окна.

## Обновление и удаление

При ручной установке сначала выгрузите группу `SHIZAAUTOMATICS` через `_CUIUNLOAD`, затем закройте AutoCAD. Перед заменой или удалением папки `ShizaAutomatics.bundle` сохраните отдельно DWG, которые добавили в библиотеку.

## Сборка

Исходники C# и AutoLISP находятся в `src`. Для сборки нужны AutoCAD 2025 x64, .NET 8 Desktop Runtime и PowerShell 7 с доступными сборками Roslyn.

```powershell
pwsh -NoProfile -File .\src\Build.ps1
```

DLL будет записана в `ShizaAutomatics.bundle\Contents`. Если AutoCAD установлен в другой папке, передайте `-AutoCADPath`.

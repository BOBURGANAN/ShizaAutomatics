# ShizaAutomatics 1.0

Надстройка для **AutoCAD 2025 под Windows x64**. Добавляет вкладку ShizaAutomatics, библиотеку блоков и переключатель масштаба оформления в нижней строке состояния.

## Установка

1. Скачайте [ShizaAutomatics-1.0.0.zip](https://github.com/BOBURGANAN/ShizaAutomatics/releases/download/v1.0.0/ShizaAutomatics-1.0.0.zip) и распакуйте его.
2. Закройте AutoCAD. Откройте в Проводнике папку `%APPDATA%\Autodesk\ApplicationPlugins`. Если папки нет, создайте её.
3. Скопируйте туда папку `ShizaAutomatics.bundle`. Проверьте, что `PackageContents.xml` находится непосредственно внутри этой папки.
4. Запустите AutoCAD 2025 и откройте чертёж. На ленте появится вкладка **ShizaAutomatics**, а в строке состояния — кнопка **Оформление 1:100**.

Сборка 1.0 без цифровой подписи. Если AutoCAD попросит разрешение, сверьте путь к `ShizaAutomatics.dll` с папкой установленной надстройки и подтвердите загрузку. Если политика вашей организации запрещает такие сборки, обратитесь к CAD-администратору. [Установка пакетов AutoCAD](https://help.autodesk.com/cloudhelp/2025/ENU/AutoCAD-Customization/files/GUID-5E50A846-C80B-4FFD-8DD3-C20B22098008.htm)

Если вкладка не видна, откройте чертёж и введите `_RIBBON`. Если пакет не загрузился, проверьте путь и версию AutoCAD. При обновлении ручной установки сначала выгрузите старый `SHIZAAUTOMATICS` через `_CUIUNLOAD`, затем закройте AutoCAD и установите пакет.

## Возможности

| Раздел | Команда | Что делает |
| --- | --- | --- |
| Исходники | `B0` | Переносит содержимое выбранных блоков на слой 0. Общие определения меняются для всех их вставок. |
| Исходники | `COPYKEEP` | Создаёт копии выбранных объектов на слое 0. |
| Исходники | `PDFROW` | Импортирует страницы PDF и размещает их в ряд. |
| Объекты из базы | `SHIZALIBRARY` | Открывает каталог DWG с категориями, поиском и миниатюрами. |
| Объекты из базы | `SHIZASAVEBLOCK` | Сохраняет выбранный блок из чертежа в библиотеку. |
| Оформление | `SHIZALEVELS` | Пересчитывает высотные отметки по опорному значению и разнице координат Y. |
| Оформление | `SHIZAALIGNLEVELS` | Выравнивает высотные отметки по опорной с сохранением высоты и числового значения каждой метки. |

Блоки категории **Оформление** вставляются в текущем масштабе. После вставки масштаб хранится у каждого экземпляра. При выделении блока оформления нижняя кнопка показывает его масштаб и меняет его по выбору. Блоки остальных категорий вставляются **1:1**.

Элементы библиотеки находятся в `ShizaAutomatics.bundle\Contents\Library`. Подпапки задают категории. Новый DWG появится в каталоге при следующем открытии окна.

## Обновление и удаление

Закройте AutoCAD. Перед заменой или удалением папки `ShizaAutomatics.bundle` сохраните отдельно DWG, которые добавили в библиотеку.

## Сборка

Исходники C# и AutoLISP находятся в `src`. Для сборки нужны AutoCAD 2025 x64, .NET 8 Desktop Runtime и PowerShell 7 с доступными сборками Roslyn.

```powershell
pwsh -NoProfile -File .\src\Build.ps1
```

DLL будет записана в `ShizaAutomatics.bundle\Contents`. Если AutoCAD установлен в другой папке, передайте `-AutoCADPath`.
